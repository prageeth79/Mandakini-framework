# Mandakini MVC Reporting Engine v2

A reusable reporting engine designed around the supplied Mandakini MVC `Controller`, `DBModel`, and `QueryBuilder` architecture.

## 1. Install dependencies

From your application's project root:

```bash
composer require dompdf/dompdf phpoffice/phpspreadsheet
```

If your application already has Composer, add these packages to its existing `composer.json` rather than using this package's composer file independently.

## 2. Add raw database rows to QueryBuilder

Add `getRaw()` from `app/core/db/QueryBuilder.patch.txt` to your existing `QueryBuilder`.

Your existing `get()` can continue returning model objects. `getRaw()` returns `PDO::FETCH_ASSOC` rows for reports.

## 3. Basic report

```php
use app\core\util\Report;

$report = Report::make('Sales Report', 'Admin')
    ->query(
        Sale::query()
            ->select([
                'customers.name AS customer',
                'sales.amount',
                'sales.sale_date',
            ])
            ->join('customers', 'customers.id', '=', 'sales.customer_id')
            ->orderBy('sales.sale_date', 'DESC')
    )
    ->addColumn('customer', 'Customer')
    ->addColumn('amount', 'Amount', ['format' => 'currency', 'align' => 'right'])
    ->addColumn('sale_date', 'Date', ['format' => 'date'])
    ->addCalculation('Total Sales', 'amount', 'SUM')
    ->setPageSize('A4')
    ->setPageOrientation('portrait')
    ->setHeader('My Company')
    ->setFooter('Generated by Mandakini');
```

## 4. Outputs

```php
$html = $report->html();
$pdf = $report->pdf();
$csv = $report->csv();
$json = $report->json();
$xlsx = $report->excel();
```

Files:

```php
$report->exportPDF('/tmp/report.pdf');
$report->exportCSV('/tmp/report.csv');
$report->exportExcel('/tmp/report.xlsx');
```

Browser download:

```php
$report->download('pdf', 'sales-report.pdf');
$report->download('excel', 'sales-report.xlsx');
```

## 5. Filters

For large datasets, prefer database-side filters through your QueryBuilder:

```php
$query = Sale::query()
    ->where('sales.status', '=', 'paid')
    ->where('sales.customer_id', '=', $customerId);

$report->query($query);
```

Report-side filters are also available for already-loaded rows:

```php
$report->addFilter('status', '=', 'paid');
$report->addFilter('amount', '>', 1000);
$report->addFilter('name', 'LIKE', 'john');
$report->addFilter('status', 'IN', ['paid', 'pending']);
```

## 6. Grouping and totals

```php
$report
    ->groupBy('class_name')
    ->addGroupCalculation('Class Total', 'amount', 'SUM')
    ->addCalculation('Grand Total', 'amount', 'SUM');
```

The HTML/PDF output shows group headers, group totals, and grand totals.

## 7. Conditional formatting

```php
$report->addConditionalFormat(
    'maths',
    '<',
    40,
    ['font-weight' => 'bold', 'background-color' => '#ffe0e0']
);
```

## 8. Logo and PDF settings

```php
$report
    ->setLogoPath(__DIR__ . '/logo.png')
    ->setPageSize('A4')
    ->setPageOrientation('landscape')
    ->showPageNumbers(true)
    ->setStyles([
        'font_size' => '10px',
        'accent' => '#333',
        'header_background' => '#eeeeee',
    ]);
```

## 9. Configuration arrays

`ReportFactory` can create a report definition from PHP configuration:

```php
use app\core\util\Report\ReportFactory;

$report = ReportFactory::fromArray([
    'title' => 'Simple Report',
    'generated_by' => 'Admin',
    'columns' => [
        'name' => 'Name',
        'amount' => ['label' => 'Amount', 'format' => 'currency'],
    ],
    'rows' => $rows,
    'page_size' => 'A4',
    'orientation' => 'portrait',
]);
```

## Architecture

```text
MVC Controller
     |
     v
   Report
     |
     +---- QueryBuilder / Array / Model rows
     |
     +---- filters / sorting / grouping / calculations
     |
     +---- HtmlRenderer
     +---- PdfRenderer (Dompdf)
     +---- CsvRenderer
     +---- JsonRenderer
     +---- ExcelRenderer (PhpSpreadsheet)
```

Keep business queries in Models/QueryBuilder and report presentation in Report/Renderer classes.

## 10. MVC response helper

If your framework does not yet have a Response object, `ReportResponse` provides a small bridge:

```php
use app\core\util\Report\ReportResponse;

ReportResponse::inlinePdf($report, 'marks.pdf');
ReportResponse::download($report, 'excel', 'marks.xlsx');
```

Once your MVC framework has a Response class, move these headers/body operations into that response class so controllers can simply return a response.
